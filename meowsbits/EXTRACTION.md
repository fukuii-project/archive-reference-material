# `meowsbits/` extraction: gists and two unlisted documents

**Not a mirror of an account.** The six repositories vendored under this prefix are whole
vendors with history, recorded in `PROVENANCE.md`. This document covers the material that is
*not* a repository: 26 public gists, and two documents that are not listed anywhere public.

The author is the Ethereum Classic core developer who wrote ECIP-1100 (MESS). They have since
left the ecosystem.

## Why an extraction and not a vendor

A gist is a git repository, so vendoring each one whole is technically possible and was
rejected: 26 subtree merges to preserve 33 small files would bury the client lineage in the
first-parent log for no gain. The files are copied and the exact revision each came from is
recorded below, which is the same posture `ethereum/EXTRACTION.md` takes.

**A gist is deletable by one person, with no fork to survive it.** That is the sharpest form of
this archive's test.

## The two documents in `documents/`

`make-etc-mutable-again.md` and `reorg-caps-vs-confirmation-values.md` analyze the July 31 and
August 5, 2020 Ethereum Classic chain reorganizations, and the distinction between a reorg cap
and a confirmation delay. They are the written argument behind ECIP-1100.

**Neither is among the author's 26 public gists.** Checked 2026-08-26: the account lists 26, and
these are not in it. The source is already not publicly enumerable, which is why they are here.

**Provenance, since there is no gist ID to cite.** Both embed images under
`user-images.githubusercontent.com/45600330/`. `GET /user/45600330` resolves to login
`meowsbits`, and `GET /users/meowsbits` returns id `45600330` -- checked both directions on
2026-08-26. Content dates the material to August 2020.

### The images were captured, and the markdown was not edited

Each document references a 960x720 PNG by absolute CDN URL. Those images carry substantive
content (a reorg-limits diagram and a cost/revenue graph) and are **not** part of the text.
Fetched 2026-08-26, both HTTP 200, into `documents/images/` under their original filenames.

**The markdown still points at the CDN URLs and was deliberately not rewritten to reference the
local copies.** Editing it would break the one property that makes a preserved copy worth
holding. The local images are a companion, not a correction. If the CDN drops them, the text
still says where they were and the bytes are here.

## Verifying, and re-deriving

Every extracted file is byte-identical to its pinned revision:

```sh
git clone https://gist.github.com/<gist-id>.git /tmp/g && git -C /tmp/g checkout <revision>
diff -r /tmp/g --exclude=.git meowsbits/gists/<gist-id>
```

**A gist revision is not immutable the way a repository tag is.** The author can force-push a
gist, and a deleted gist takes its revisions with it. If a revision above no longer resolves,
that is the disappearance this extraction exists to survive, not a defect here.
